# FoxRevive Downloads

**FoxRevive** is a one-click PC cleanup and repair app for Windows 10 and 11, made by **FoxZoneIT**.

## Download
Get the latest version from the [Releases page](https://github.com/FoxZoneIT/foxrevive-downloads/releases/latest).

## Requirements
- Windows 10 or Windows 11 (64-bit)
- An active FoxRevive plan (Swift or Apex) to run a tune-up. Without a plan, FoxRevive runs a read-only Preview scan.
- 1 PC per license
